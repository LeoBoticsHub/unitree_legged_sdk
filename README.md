# unitree_legged_sdk v3.8.3

The unitree_legged_sdk is mainly used for communication between PC and Controller board.
It also can be used in other PCs with UDP.

support robot: B1

## Dependencies

* [Boost](http://www.boost.org) (version 1.71.0 or higher)
* [CMake](http://www.cmake.org) (version 3.16.3 or higher)
* [g++](https://gcc.gnu.org/) (version 9.4.0 or higher)

## Build and install

To install the sdk library on your computer run the following:

```bash
    mkdir build
    cd build
    cmake ../
    sudo make install
```
